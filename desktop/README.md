# Резонанс для ПК

Живые обои и строка с плеером для Windows 11.

- **Обои** — волны Резонанса во весь рабочий стол, под значками. Слышат любой звук
  компьютера: музыку, видео, игры. Отдыхают, пока экран закрыт развёрнутым окном.
- **Строка сверху** — логотип (меню), что играет в любом плеере (Яндекс Музыка,
  Spotify, браузер — всё, что видно в медиа-кнопках Windows), кнопки, дата и время.
  Развёрнутые окна встают под неё; в полноэкранной игре или видео она прячется.
- **Меню** — значок в трее или логотип на строке: стиль волн, цвета, фон, автозапуск.

Сборка: GitHub Actions (`.github/workflows/build-desktop.yml`) на Windows — помощник
`host/` (C#, .NET Framework 4.8), страницы `web/` (общие волны из `../src/waves.js`),
Electron + установщик NSIS. Каждая сборка запускается на машине сборки и
фотографирует экран (ветка `ci-smoke`).
