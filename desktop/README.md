# Резонанс для ПК

Живые обои, остров-плеер и Windows в цветах Резонанса — для Windows 11.

- **Обои** — волны Резонанса во весь рабочий стол, под значками. Слышат любой звук
  компьютера: музыку, видео, игры. Восемь стилей (свои «Капсулы» для большого
  экрана, «Горизонт», «Сфера»), одиннадцать палитр, включая цвета из обложки песни.
  Отдыхают, пока экран закрыт развёрнутым окном. После смены наушников или колонок
  сами начинают слушать новое устройство.
- **Слова за волнами** — строчки песни в такт (LRCLIB), название песни, часы или
  свой текст: большим мягким шрифтом позади волн.
- **Фоны** — Liquid Glass (фиолетовый, чёрный, в цвет волн), северное сияние, угли,
  тёмный, AMOLED, свои обои Windows или любой рисунок (с затемнением и размытием).
- **Строка сверху** — логотип, дата и время. Развёрнутые окна встают под неё; в
  полноэкранной игре или видео она прячется.
- **Остров** — плеер посередине строки: обложка в кружке с прогрессом и эквалайзер.
  Наведи мышь — он засветится и раскроется вниз: обложка, время, перемотка, кнопки.
  Работает с любым плеером, который видно в медиа-кнопках Windows (Яндекс Музыка,
  Spotify, браузер…).
- **Панель Резонанса** — вместо обычного меню: логотип на строке или значок в трее.
  Все настройки — вживую.
- **Windows в цветах Резонанса** — акцент, цвет выделения и (по желанию) тёмная
  тема в цветах палитры. Прежние цвета запоминаются и возвращаются одной кнопкой.

Сборка: GitHub Actions (`.github/workflows/build-desktop.yml`) на Windows — помощник
`host/` (C#, .NET Framework 4.8), страницы `web/` (общие волны из `../src/waves.js`),
Electron + установщик NSIS. Версия берётся из `package.json`. Каждая сборка
запускается на машине сборки и фотографирует экран в нужные моменты (ветка
`ci-smoke`).
