# Резонанс OS

Домашний экран для ТВ-приставок на Android — SberBox, SberBox 2 и других.
В том же стиле, что приложение «Резонанс» и «Резонанс для ПК», только для всего
телевизора, а не для одной музыки.

- **Главный экран** — большие часы с приветствием, дата и погода (место
  определяется по интернету), «Сейчас играет» с обложкой и кнопками (любое
  приложение: Okko, YouTube, музыка…).
- **Приложения** — ряд «Избранное» с большими баннерами и ряд всех остальных.
  Выбранное приложение подсвечивает комнату своим цветом; по карточке пробегает
  блик. Удержи OK — меню: в избранное, переставить, скрыть, удалить.
- **Волны Резонанса** за «Сейчас играет» — слышат звук телевизора.
- **Заставка** — часы и волны через несколько минут без нажатий.
- **Настройки** — фон, палитра, стиль волн, заставка, плавность, кнопка «Домой».

## Как поставить

Нужен компьютер с Windows в той же сети, что и приставка.

1. Включи отладку на приставке. На SberBox: войди в [Studio](https://developers.sber.ru/studio)
   под тем же Сбер ID, что и на приставке → Настройки → Настройки сервисов → SmartApp →
   Мои устройства → добавь приставку (идентификатор — в разделе «Об устройстве» на
   приставке) и включи ADB. Подробно: [документация Сбера](https://developers.sber.ru/docs/ru/va/native/testing/adb).
2. Скачай из выпуска `Rezonans-OS-….apk` и `Install-Rezonans-OS.cmd` в одну папку.
3. Запусти `Install-Rezonans-OS.cmd`, введи IP-адрес приставки (Настройки → Сеть).
   Если на телевизоре спросят про отладку — «Разрешить».

Установщик сам скачает adb от Google, поставит Резонанс OS, выдаст разрешения
(звук для волн, «Сейчас играет», служба кнопки «Домой») и сделает его домашним
экраном. Вернуть экран Сбера — `Restore-Sber-Home.cmd`.

Без компьютера: APK можно загрузить на [apps.sber.ru/my](https://apps.sber.ru/my) и
поставить на приставке из «Мои приложения → Загруженное». Тогда Резонанс OS
откроется как приложение, но кнопка «Домой» останется за экраном Сбера.

## Устройство

- `android/` — маленькое приложение на Java без библиотек: WebView во весь экран,
  мост к системе (список приложений, баннеры, запуск, медиасессии, Visualizer),
  служба специальных возможностей, которая возвращает Резонанс OS, когда приставка
  открывает свой экран.
- `web/` — сам интерфейс (собирается `node tv/build.mjs` в `android/app/src/main/assets/www`).
  Общие волны — из `src/waves.js` и `desktop/web/looks.js`.
- CI (`.github/workflows/build-tv.yml`) собирает APK, запускает его на эмуляторе
  Android TV, нажимает кнопки пульта и фотографирует экран (ветка `ci-smoke-tv`).
