# Слух

Один плеер для Звука и своих MP3 на Android.

- плейлисты и лайки из Звука, поиск по Звуку
- свои MP3 с обложками и тегами, хранятся внутри приложения
- свои плейлисты, где Звук и MP3 вперемешку
- лента: новинки твоих артистов, похожие артисты, микс
- нет трека в Звуке — играет твой MP3 с той же песней, и наоборот; если нет нигде — кнопка поиска в VK Музыке, Яндекс Музыке, YouTube Music, SoundCloud
- управление с экрана блокировки и наушников

## Установка

1. Открой раздел **Releases** справа на странице репозитория и выбери последнюю версию.
2. Скачай файл `Slukh-1.0.N.apk` и открой его на телефоне.
3. Разреши установку из этого источника, если телефон спросит.

Новая версия ставится поверх старой, MP3 и плейлисты сохраняются.

## Вход в Звук

В приложении: Профиль → инструкция. Коротко: войти на zvuk.com в браузере, открыть
`https://zvuk.com/api/tiny/profile`, скопировать значение `token` и вставить в приложение.
Токен — ключ от аккаунта, никому его не показывай.

## Важно

Доступ к Звуку неофициальный (тот же, что у сайта zvuk.com). Если Звук что-то поменяет,
часть функций может перестать работать до обновления приложения.

Если музыка обрывается при выключенном экране: Настройки телефона → Приложения → Слух →
Батарея → «Без ограничений».

## Сборка

APK собирается автоматически на GitHub при каждом изменении в ветке `main`
(`.github/workflows/build-apk.yml`). Локально: `npm ci && npm test && npm run sync`,
затем `./gradlew assembleRelease` в папке `android`.
