# Резонанс Лаунчер

Домашний экран Android для телефонов и планшетов в стиле Резонанса: тёмные сливовые чернила, акценты палитры, волны из `src/waves.js`, шрифты Unbounded и Onest.

- Главный экран: часы и дата (нажатие открывает часы/календарь), «Сейчас играет» с кнопками, свои приложения сеткой 4×N, поиск, док.
- Свайп вверх — ящик со всеми приложениями: идёт за пальцем, поиск (русский/латиница, неправильная раскладка, транслит, «тлг» → Telegram), буквы сбоку для быстрой прокрутки, «Часто».
- Свайп вниз — шторка уведомлений.
- Долгое нажатие на значок — меню (ярлыки приложения, на экран/убрать, о приложении, удалить); не отпуская и двигая — перетаскивание по сетке и доку, наверх в «Убрать». Из ящика — перетаскивание на главный экран.
- Долгое нажатие на пустом месте — настройки: палитра, вид волн, «волны слышат музыку», подписи.

Устройство:
- `web/` — страница (esbuild: `node launcher/build.mjs` → `android/app/src/main/assets/www/`).
- `android/` — оболочка: Activity (HOME) с WebView, мост `window.RezL` (приложения, значки, ярлыки, медиа, точки уведомлений, вибро, шторка).
- `test/serve.mjs` — посмотреть в браузере с поддельным телефоном: `LAUNCHER_OUT=<папка> node launcher/build.mjs && LAUNCHER_OUT=<папка> node launcher/test/serve.mjs`.
- `ci/smoke.sh` — проверка на эмуляторе в CI, снимки в ветку `ci-smoke-launcher`.

Ветка `launcher-dev` — тестовые сборки, `main` — релиз с тегом `launcher-v*`.
