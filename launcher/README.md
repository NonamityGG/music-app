# Резонанс Лаунчер

Домашний экран Android для телефонов и планшетов. Всё, что есть у Резонанс OS (ТВ), «Резонанса для ПК» и музыкального приложения: волны, которые слышат звук, палитры, виджеты, ящик приложений.

- `web/` — страница: рабочий стол, ящик, папки, настройки, виджеты. Собирается esbuild (`node launcher/build.mjs`) в `android/app/src/main/assets/www/`.
- `android/` — оболочка: Activity (HOME) с WebView, мост `window.RezL`, значки приложений, фоновые «живые обои» (`RezWallpaper`), счётчики уведомлений, «Сейчас играет».
- `test/` — просмотр в браузере с поддельным телефоном: `node launcher/test/scenarios.mjs <папка>`.
- `ci/smoke.sh` — проверка на эмуляторе в CI.

Ветка `launcher-dev` — тестовые сборки, `main` — релиз с тегом `launcher-v*`.
